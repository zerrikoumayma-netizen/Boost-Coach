# Boost-Coach
Decathlon Sport Buddy 🏋️‍♂️🚴‍♀️  Decathlon Sport Buddy est une application web full-stack dédiée au coaching sportif et à la recommandation de produits sportifs inspirés de l’univers Decathlon. Le projet combine un backend sécurisé en Spring Boot, un frontend moderne en React et une base de données MySQL conteneurisée avec Docker.
